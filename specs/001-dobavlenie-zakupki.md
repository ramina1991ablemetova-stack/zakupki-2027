# Добавление закупки в сетевой график

## Для кого и зачем

Для сотрудника, планирующего закупки: чтобы занести закупку в сетевой график и видеть её основные данные и общую сумму закупок.

## Что должно быть

- Форма добавления с полями «Наименование», «Сумма без НДС», «Вид затрат» и «Ответственный» и кнопкой добавления.
- Все поля обязательны. Сумма должна быть положительным числом с не более чем двумя знаками после запятой. При ошибке показать понятное сообщение и сохранить введённые данные для исправления.
- После успешного добавления показать закупку в графике со всеми указанными полями, обновить общую сумму и очистить форму.
- Сохранить закупки в localStorage и восстановить их после обновления страницы.

## Примеры

- «Бумага для офиса», 100 000,00 ₸ без НДС, «Материалы», «Айдана Садыкова».
- «Учебное оборудование», 200 000,00 ₸ без НДС, «Оборудование», «Тимур Асанов».
- Для этих двух вымышленных закупок общая сумма составляет 300 000,00 ₸ без НДС.
- Если сумма не указана, закупка не добавляется, а пользователь видит сообщение о необходимости заполнить поле.
- Если указана отрицательная сумма, закупка не добавляется, а пользователь видит сообщение о необходимости указать положительную сумму.
- Сумма 125 000,55 ₸ без НДС принимается и отображается с точностью до двух знаков после запятой.

## Ограничения

- Использовать HTML, CSS и JavaScript; интерфейс — на русском языке.
- Все суммы указывать в тенге без НДС с двумя знаками после запятой; исключить ошибки округления и NaN.
- Поддерживать экраны шириной от 375 px; кнопки и поля должны быть не менее 44 px.
- Использовать только вымышленные примеры. Не изменять существующие работающие функции без согласования.

## Готово, когда

- Закупка с четырьмя заполненными полями добавляется и отображается в графике.
- Пустые поля и некорректная сумма не позволяют добавить закупку; пользователь видит причину.
- Две закупки из примера дают итог 300 000,00 ₸ без НДС.
- После F5 закупки и итог сохраняются.
- Интерфейс доступен на экране шириной 375 px, а кнопки и поля соответствуют минимальному размеру.
