# Добавление закупки в сетевой график

## Для кого и зачем

Для сотрудника, планирующего закупки: чтобы заносить закупки в сетевой график, разделять их по очередности и видеть основные сведения о каждой закупке.

## Что должно быть

- Сетевой график представлен таблицей с двумя разделами: «Первоочередные закупки» и «Непервоочередные закупки». Каждая закупка занимает строку в соответствующем разделе.
- Для каждого раздела предусмотрено отдельное добавление закупки; добавленная запись попадает именно в выбранный раздел.
- При добавлении указываются «Наименование», «Сумма без НДС», «Потребность / договор», «Номер договора», «Поставщик / примечание», «Ответственный», «Сумма договора без НДС», «Отклонение от суммы договора», «Материал SAP», «Вид затрат» и «Статус закупки». Указанные сведения отображаются в таблице.
- Наименование, сумма без НДС, вид затрат и ответственный обязательны, как в первоначальной спецификации. До заключения договора поля «Номер договора», «Поставщик / примечание», «Сумма договора без НДС» и «Отклонение от суммы договора» могут оставаться пустыми. Обязательность остальных полей и правила ввода отклонения требуют уточнения до реализации изменений.
- Сумма без НДС должна быть положительным числом с не более чем двумя знаками после запятой. При ошибке показать понятное сообщение и сохранить введённые данные для исправления.
- После успешного добавления показать закупку в выбранном разделе и очистить форму. Сохранить закупки вместе с разделом в localStorage и восстановить их после обновления страницы.
- Предусмотреть редактирование добавленной закупки: открыть её данные, изменить поля и сохранить изменения. При ошибке показать причину и сохранить введённые данные для исправления; до успешного сохранения исходная запись не изменяется. Сохранённые изменения отображаются в таблице и сохраняются в localStorage.
- Помесячный план и факт с января по декабрь и автоматический расчёт итогов относятся к отдельной функции и в эту спецификацию не входят. Существующие работающие функции не изменяются без согласования.

## Примеры

- В разделе «Первоочередные закупки»: «Бумага для офиса», 100 000,00 ₸ без НДС, потребность «Офисные материалы», договор № Д-001, поставщик «ТОО Пример», ответственный Айдана Садыкова, сумма договора 100 000,00 ₸ без НДС, отклонение 0,00 ₸, материал SAP «MAT-001», вид затрат «Материалы», статус «Планируется».
- В разделе «Непервоочередные закупки»: «Учебное оборудование», 200 000,00 ₸ без НДС, потребность «Оснащение учебного класса», договор № Д-002, поставщик «ТОО Учебный пример», ответственный Тимур Асанов, сумма договора 200 000,00 ₸ без НДС, отклонение 0,00 ₸, материал SAP «MAT-002», вид затрат «Оборудование», статус «Планируется».
- Если сумма не указана, закупка не добавляется, а пользователь видит сообщение о необходимости заполнить поле.
- Если указана отрицательная сумма, закупка не добавляется, а пользователь видит сообщение о необходимости указать положительную сумму.
- Сумма 125 000,55 ₸ без НДС принимается и отображается с точностью до двух знаков после запятой.
- Закупку до заключения договора можно добавить с пустыми номером договора, поставщиком / примечанием, суммой договора и отклонением, а после заключения договора — отредактировать и заполнить эти поля.

## Ограничения

- Использовать HTML, CSS и JavaScript; интерфейс — на русском языке.
- Все суммы указывать в тенге без НДС с двумя знаками после запятой; исключить ошибки округления и NaN.
- Поддерживать экраны шириной от 375 px; кнопки и поля должны быть не менее 44 px.
- На узком экране таблица должна оставаться доступной для просмотра всех полей, например с помощью горизонтальной прокрутки.
- Использовать только вымышленные примеры. Не изменять существующие работающие функции без согласования.

## Готово, когда

- Таблица содержит оба раздела; закупку можно отдельно добавить в каждый из них, и она отображается в выбранном разделе со всеми указанными сведениями.
- Пустые обязательные поля и некорректная сумма не позволяют добавить закупку; пользователь видит причину, введённые данные сохраняются для исправления.
- Сумма 125 000,55 ₸ без НДС принимается и отображается с двумя знаками после запятой.
- После F5 закупки, их поля и принадлежность к разделам сохраняются.
- Добавленную закупку можно отредактировать; после сохранения изменения видны в её строке и сохраняются после F5. Некорректные изменения не перезаписывают исходную запись.
- На экране шириной 375 px доступны все поля таблицы, а кнопки и поля соответствуют минимальному размеру.
- Помесячный план, факт и автоматический расчёт итогов рассматриваются в отдельной функции.
