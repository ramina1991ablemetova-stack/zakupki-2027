# Сетевой график закупок

Откройте `index.html` в современном браузере. Вводите и редактируйте данные прямо в ячейках таблицы выбранного раздела. Когда пустая строка заполняется, появляется следующая. Для каждой закупки месяцы показаны столбцами, а план, факт и отклонение — строками. На узких экранах месяцы размещаются группами по три без горизонтальной прокрутки.

Изменения автоматически сохраняются в localStorage текущего браузера и восстанавливаются после обновления страницы. При ошибке сохранения данные остаются на странице; для повторной попытки измените ячейку. Некорректное денежное значение подсвечивается и не сохраняется, пока не будет исправлено. Суммы вводятся с запятой или точкой и не более чем двумя знаками после неё. Сумма договора неотрицательна, отклонение может быть отрицательным. Суммы указываются в тенге без НДС.

Денежные значения показываются с двумя знаками и символом ₸, проценты — с двумя знаками и символом %. При вводе сумма форматируется после выхода из поля. Деньги рассчитываются в целых тиынах; проценты округляются до сотых, а при нулевом или пустом знаменателе вместо процента выводится прочерк.

Ранее сохранённые записи сохраняют свои данные; записи без раздела отображаются среди первоочередных. Прежний общий итог показывает суммы закупок предыдущей версии, которые больше не редактируются в таблице. Для каждого месяца 2027 года доступны план и факт, отклонение рассчитывается как факт минус план. Итоги суммируются за год, остаток равен сумме договора за вычетом факта. Итоговая строка показывает суммы по разделу; если сумма договора не указана, остаток обозначен прочерком. Расчёты выполняются в тиынах.

В каждом разделе кнопка «+ Добавить закупку» создаёт дополнительную запись. Освоение договора равно годовому факту, делённому на сумму договора; месячное отклонение в процентах равно разнице факта и плана, делённой на план. При нулевом или пустом знаменателе показывается прочерк. Проценты рассчитаны по суммам и отображаются с двумя знаками. При абсолютном отклонении от 10% ячейка оранжевая, от 20% — красная с текстовым предупреждением; пороги сравниваются до округления. Итоги раздела рассчитывают проценты по суммарным значениям.

При открытии выберите «Просмотр» или «Редактирование». В режиме просмотра данные доступны без изменения, добавления и удаления через интерфейс. Для редактирования введите код 1991 и имя автора; неверный код выводит «Доступ запрещён». Кнопка «Переключить режим» позволяет сменить режим; при каждом переходе к редактированию код запрашивается снова.

Сохранённые изменения выделяются жёлтым в графике. На вкладке «История изменений» показаны местные дата и время, автор, закупка, поле и значения до и после изменения. Историю можно фильтровать по дате и названию закупки; прежнее значение показано серым, новое — жёлтым. Каждая сохранённая правка сохраняется вместе с данными после обновления страницы.

Проверка кода и локальный журнал демонстрационные: код, имя и историю можно изменить средствами браузера. Время берётся с устройства. Firebase, общий доступ и защищённый журнал изменений не настроены. Данные и история доступны только в localStorage текущего браузера и не синхронизируются между устройствами.
