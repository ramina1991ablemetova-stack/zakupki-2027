# AGENTS.md — Сетевой график закупок

## О проекте
Веб-приложение для планирования закупок, распределения бюджета по месяцам и контроля сроков исполнения.

Файлы:
- index.html — структура страницы.
- styles.css — дизайн.
- script.js — логика.
- specs/ — требования к функциям.
- README.md — описание проекта.

## Правила
- Используй только HTML, CSS и JavaScript.
- Храни данные в localStorage.
- Интерфейс на русском языке.
- Все денежные суммы показывай в тенге без НДС строго с двумя знаками после запятой и символом ₸; проценты — строго с двумя знаками и символом %. Пустые значения и неопределённые отношения показывай согласно спецификации.
- Денежные расчёты выполняй в целых тиынах; проценты округляй до двух знаков без ошибок двоичной арифметики. Не допускай NaN и Infinity, включая деление на ноль.
- Поддерживай экран шириной от 375px.
- Кнопки и поля не меньше 44px.
- Не изменяй работающие функции без согласования.
- Используй только вымышленные данные.
- Не запускай Git и не публикуй проект самостоятельно.

## Новая функция
- Сначала создай файл specs/NNN-nazvanie.md.
- Разделы: Для кого и зачем, Что должно быть, Примеры, Ограничения, Готово, когда.
- Не пиши код до команды «Делай».
- После реализации обнови README.md.

## Как проверить
- Открыть index.html в браузере.
- Проверить расчет: 100 000 + 200 000 = 300 000 тенге.
- После F5 данные должны сохраняться.
